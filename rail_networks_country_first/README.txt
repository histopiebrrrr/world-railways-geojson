COUNTRY-FIRST RAIL NETWORK FILES

Folder order: COUNTRY / SCALE / CITY / NETWORK.geojson
For national/international routes: COUNTRY / SCALE / NETWORK.geojson.
Each country ZIP contains only that country's existing filing group.
INDEX.csv lists the included files and their new paths.

The original 5,032 GeoJSON files are copied byte-for-byte: no lines, colours,
features or classification tags were changed. Files remain under 4.5 MB each.

Country and city assignments retain the previous approximate geographic
anchors. They are not boundary clips: cross-border routes remain complete
under their existing anchor country. Unclassified scales remain unclassified.
Some territory codes have separate folders, consistent with the source index.

SCALES
01_urban_by_city: metro, tram, light rail, monorail, funicular
02_regional_commuter_by_city: regional and commuter trains
03_national_international: national/international and long-distance trains
04_special_services_by_city: tourist and other special services
05_unclassified_by_city: train routes with unclear scale

Original coverage and colour limitations remain. No buses/ferries were added.
